# Geodashboard

Source of the Angular library `@geodienst/geodashboard`: reusable components for map dashboards.
Installation and setup in an app: see [the package README](projects/geodienst/geodashboard/README.md).

## Development

```powershell
npm ci          # install dependencies
npm test        # unit tests (Vitest)
npm run build   # builds the package to dist/geodienst/geodashboard
```

Releasing a new version: see "Release" in [CLAUDE.md](CLAUDE.md).
